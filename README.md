# 自动喂食槽 · Auto Feeder

Minecraft **Forge 1.20.1** 的动物养殖自动化 mod：**食物槽**让动物自己繁殖，**剪毛机、挤奶机、集蛋机、钓鱼机**替你收羊毛、牛奶、鸡蛋和鱼。所有机器都带数量上限和间隔配置，防止把服务器养卡。

> English: [README_EN.md](README_EN.md)　|　许可证 / License：[MIT](LICENSE)　|　更新日志：[CHANGELOG.md](CHANGELOG.md)

> ⚠️ **这是 0.1.0 早期版本。** 欢迎到 [Issues](https://github.com/xiaofeiwuuu/auto-feeder/issues) 反馈问题。

## 安装

1. 安装 **Minecraft 1.20.1** 和 **Forge 47.x**。
2. 把 `auto-feeder-forge-1.20.1-<版本>.jar` 放进 `mods/` 文件夹（**先删掉旧版本**）。
3. **服务端和客户端都要装同一个版本。** 这个 mod 新增了方块，所以没装的玩家进不了装了它的服务器。
4. 不依赖任何其他 mod。

## 内容

| 方块 | 大小 | 作用 |
|---|---|---|
| **食物槽** | 1×1 | 放进食物，附近的动物自动进入繁殖状态；顺便喂幼崽让它们长得快些；收集繁殖掉落的经验 |
| **长食物槽** | 1×2 | 同上，容量是普通槽的两倍（18 格） |
| **剪毛机** | 1×2，2 格高 | 放入剪刀，自动剪范围内的羊、蘑菇牛等可剪动物 |
| **挤奶机** | 1×2，2 格高 | 放入空桶，自动挤范围内的成年牛、蘑菇牛、山羊 |
| **集蛋机** | 1×2，2 格高 | 吸收范围内鸡下的蛋，不需要输入 |
| **钓鱼机** | 1×2 | 放入钓鱼竿，在水边自动钓鱼；鱼竿和线会伸到前方的水面上 |

### 合成

| 方块 | 合成 |
|---|---|
| 食物槽 | 7 石头 + 1 木桶（`S S / SBS / SSS`） |
| 长食物槽 | 2 个食物槽（无序） |
| 剪毛机 / 挤奶机 / 集蛋机 / 钓鱼机 | 7 石头 + 1 木桶 + 中间上方放：**剪刀 / 桶 / 漏斗 / 钓鱼竿**（`SIS / SBS / SSS`） |

### 食物槽

- **手持食物右键**：放进去；**潜行 + 空手右键**：把里面的食物全部取回。
- **空手右键**：取出存着的经验；没有经验可取时，聊天栏列出范围内每种动物的数量、可繁殖数量，以及是否已达上限。
- 每隔 5 秒（可配置）扫描周围 6 格（可配置）：
  - 某种动物里有至少 **2 只**成年、不在冷却的，才会喂，避免浪费；
  - 同种动物数量（含幼崽）达到上限（默认 12）就不再喂；
  - 每轮最多喂 4 只。
- **幼崽**：只在它们还要长超过 300 秒时才喂。原版每次喂食只缩短**剩余时间的 10%**，剩得越少越不划算，所以后期不再浪费食物。
- **经验**：动物繁殖掉落的经验球，会在**喂食后的 45 秒内**被吸进槽里存起来（默认最多 2000 点），空手右键取出。窗口之外不吸，所以不会抢走你旁边打怪掉的经验。
- 可以用漏斗往里灌食物（只收食物标签里的东西）。

### 机器的通用操作

- **手持对应物品右键**：装进去（剪刀、桶、钓鱼竿）。集蛋机没有输入。
- **空手右键**：取走全部产物和存着的经验。
- **潜行 + 空手右键**：把装进去的工具取回。
- 漏斗：可以往输入格灌物品，也可以从输出格（9 格）抽走产物。**漏斗要接在你放置时点的那一格**（后半最下层），不是另一格。
- 拆掉任何一格，整台机器一起拆掉，里面的东西全部掉出来，只掉一个方块。
- 放置时，机器占据的所有格子（含上方）必须是空的；你面对的方向决定它朝哪边延伸。

| 机器 | 工作方式 |
|---|---|
| 剪毛机 | 每次剪一只，剪刀磨损 1 点，用完损坏；产物是羊毛、蘑菇等 |
| 挤奶机 | 每挤一只用掉 1 个空桶，产出奶桶；**奶桶产量只取决于你放了多少桶**，不受动物限制；输出满了就停 |
| 集蛋机 | 只拿蛋，不会吸走旁边其他掉落物 |
| 钓鱼机 | 默认 30 秒钓一次，读取原版钓鱼战利品表（不同群系掉落不同）；鱼竿**饵钓**每级缩短 5 秒（最快 5 秒）、**海之眷顾**提高好东西概率；每钓一次鱼竿磨损 1 点；每次产出 1~6 点经验，存在机器里 |

### 钓鱼机怎么放

- 机器**前方（第二格再往前的那一格）要是水**，浮标就画在水面上；外观按"水面比机器低一格"设计。
- 需要周围（水平 3 格、向下 3 格）至少 **9 格水**（可配置）。
- 没放鱼竿时不工作，外观上也没有鱼竿。

## 支持的动物

食物槽读取每种动物自己的"能吃什么"，所以原版所有能繁殖的动物都支持：

| 动物 | 食物 |
|---|---|
| 牛、羊、山羊、蘑菇牛 | 小麦 |
| 猪 | 胡萝卜、土豆、甜菜根 |
| 兔子 | 胡萝卜、金胡萝卜、蒲公英 |
| 鸡 | 小麦种子、西瓜籽、南瓜籽、甜菜种子、火把花种子、瓶子草荚果 |
| 嗅探兽 | 火把花种子 |
| 马、驴、骡 | 金苹果、附魔金苹果、金胡萝卜 |
| 羊驼 | 干草块 |
| 骆驼 | 仙人掌 |
| 狐狸 | 甜浆果、发光浆果 |
| 熊猫 | 竹子 |
| 海龟 | 海草 |
| 蜜蜂 | 任何花 |
| 青蛙 | 粘液球 |
| 炽足兽 / 疣猪兽 | 扭曲菌 / 绯红菌 |
| 猫、豹猫 | 生鳕鱼、生鲑鱼 |
| 狼 | 各种生熟肉、腐肉 |

- **马、驴、骡**只认金色食物才会进入繁殖状态（原版里小麦、糖、干草只能治疗和催熟，不能繁殖），免得槽比原版更便宜。
- **狼和猫**只有驯服的才会繁殖，也就是你的宠物。不想让食物槽自动繁殖宠物，就把它们加进黑名单。
- **其他 mod 的动物**：只要继承了原版的繁殖类并正确实现"吃什么"，就会自动兼容；把它们的食物加进食物标签就行（见下）。

## 配置

在**存档**的 `serverconfig/autofeeder-server.toml`（专用服务器是 `world/serverconfig/`）：

| 配置项 | 默认 | 说明 |
|---|---|---|
| `range` | 6 | 食物槽的范围（以方块为中心的立方体，向每个方向延伸这么多格；范围 1~16） |
| `intervalTicks` | 100 | 食物槽两轮喂食间隔（20 刻 = 1 秒） |
| `maxSameTypeNearby` | 12 | 范围内同种动物（含幼崽）达到这个数量就不再喂 |
| `maxFedPerCycle` | 4 | 每轮最多喂几只 |
| `babyFeedMinSeconds` | 300 | 幼崽还要长超过这么多秒才喂 |
| `blacklist` | `[]` | 不喂的实体 ID，如 `["minecraft:wolf", "alexsmobs:grizzly_bear"]`；它们仍然计入同种数量 |
| `collectXp` | `true` | 是否吸收繁殖掉落的经验 |
| `maxStoredXp` | 2000 | 一个槽或机器最多存多少经验 |
| `machineRange` | 6 | 剪毛机、挤奶机、集蛋机的范围 |
| `machineIntervalTicks` | 100 | 它们两轮之间的间隔（集蛋机固定 40） |
| `machineMaxPerCycle` | 4 | 剪毛机、挤奶机每轮最多处理几只 |
| `fisherIntervalTicks` | 600 | 钓鱼机钓一次的间隔（600 = 30 秒） |
| `fisherMinWater` | 9 | 需要的最少水方块数 |
| `fisherRange` | 3 | 找水的水平半径（另外向下看 3 格） |

**范围**是以**放置的那一格**（机器后半最下层）为中心的立方体，不是机器的中点。

### 追加可喂的食物

食物槽只收**食物标签** `autofeeder:feed` 里的物品。数据包或整合包里放一个文件即可追加（也可以用 KubeJS）：

```json
// data/autofeeder/tags/items/feed.json
{ "replace": false, "values": ["somemod:special_feed"] }
```

标签只决定"槽里能放什么"，动物吃不吃由它自己判断，所以放进去的东西不会被乱喂。

## 已知限制

- 仅支持 **Forge 1.20.1**（47.x），不支持 Fabric 和其他游戏版本；**服务端和客户端都要装**。
- **只处理已加载区块里的动物**，你走远、区块卸载后，机器就停了（和原版红石机器一样）。
- **钓鱼机钓不到宝藏**（附魔书、鞍、睡莲、命名牌等）：宝藏要求"鱼钩在开阔水域"，机器没有真的鱼钩。产出的是鱼和垃圾。
- 钓鱼机判断"有水"只数水方块的数量，不区分是否开阔水域；一个小水坑也能用，嫌宽松就调高 `fisherMinWater`。
- 方块外观**全部用原版贴图拼成**，钓鱼机的鱼竿是用小方块拼出的阶梯形，不是平滑的斜杆；鸡蛋是白色方块。想换成自己的贴图，替换资源包里的图片即可。
- 蝾螈（吃热带鱼桶）和鹦鹉（不是可繁殖动物）暂不支持。
- **0.x 版本之间方块的状态可能改变**，升级后已放置的旧机器可能显示异常，需要拆掉重放；升级前先把里面的东西取出来。
- 这是早期版本，欢迎反馈。

## 从源码构建

需要 JDK 17。

```bash
./gradlew build          # 编译 + 运行单元测试，产物在 build/libs/
./gradlew runClient      # 启动开发用客户端
./gradlew runServer      # 启动开发用服务端
```
