## 三、CurseForge / GitHub Release

- **CurseForge**：同样的信息；Project ID 要等创建后才有，不需要提前填。
- **GitHub Release**：tag `v0.1.0`，标题"自动喂食槽 0.1.0"，勾 **Pre-release**，附上 jar，说明取自 `CHANGELOG.md`。
- **jar 的 SHA-256** 每次构建都会变，发布前再用 `shasum -a 256 build/libs/*.jar` 算一次，不要沿用旧值。

## 四、发布前自查

- [ ] 在**干净的** Forge 1.20.1 环境里（只装 Forge 和这个 mod）进一次世界：创造栏里能找到六个方块、合成配方能用、放置和拆除正常。
- [ ] 在**专用服务器**上试一次（单人世界和专用服务器的同步行为不一样）：客户端也装了的玩家能进，没装的玩家被拒绝。
- [ ] 食物槽：喂牛，看是否繁殖；放两种以上的动物，确认数量上限生效。
- [ ] 四台机器各放一台，重点看**放置、拆除、掉落物、漏斗**。
- [ ] 钓鱼机：水在机器**下一格**时，浮标是否贴着水面。
- [ ] 版本号：`gradle.properties` 里的 `mod_version`。
- [ ] 图标：见下。

## 五、待办 / 要你决定的

1. **图标还没有。** Modrinth 不强制，但没有图标的项目页很不起眼。我没法画图：你可以自己做一张 256×256 的 PNG，放到 `src/main/resources/logo.png`，并在 `mods.toml` 里加 `logoFile="logo.png"`。如果用别人的图，请确认使用授权。
2. **没有截图。** 建议在游戏里截 3~4 张（食物槽喂牛、钓鱼机放在水边、四台机器的合照、剪毛机或挤奶机的特写），传到 Modrinth 的 Gallery。
3. **modId `autofeeder` 以后不能改**：它决定玩家存档里方块的注册名，改了会让所有已放置的方块消失。展示名可以随时改。
4. **0.x 期间方块状态可能再变**（比如机器大小），已经放置的旧机器会显示异常。第一版发布后尽量少改，改了要在更新日志里写明。
5. 这个 mod 的**大部分内容在发布前还没有逐项实测过**，所以我建议用 Beta，并在页面上明确写"早期版本"（已经写进描述了）。

## 六、一个提醒

同类的"自动化养殖 / 喂食器"在 Modrinth 和 CurseForge 上已经有一些。你的差异点是：**一套机器（喂食 + 剪毛 + 挤奶 + 集蛋 + 钓鱼）+ 数量上限防卡服 + 配置齐全**。描述里已经把这几点放在最前面。
